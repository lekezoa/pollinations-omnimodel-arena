# ⚡ OmniModel Arena

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**OmniModel Arena** is an open-source web application built for **POLLEN-QUEST #19183** that broadcasts any central dilemma, philosophical question, or technical query to 6 top AI models simultaneously through the unified **Pollinations.ai** API (`gen.pollinations.ai`).

## 🌐 Live Web App
- **Live Demo:** [https://lekezoa.github.io/pollinations-omnimodel-arena/](https://lekezoa.github.io/pollinations-omnimodel-arena/)

## 🚀 Features
- **Parallel Multi-Model Broadcast:** Simultaneously queries:
  - `openai` (GPT-4o)
  - `mistral` (Mistral Large)
  - `claude-hybrid` (Claude via Pollinations)
  - `deepseek` (DeepSeek-V3)
  - `gemini` (Gemini Flash)
  - `qwen` (Qwen 2.5 72B)
- **Controversial Take & Perspective Comparison:** Direct side-by-side comparative grid to observe how different model families approach the same controversial human topic.
- **Bring Your Own Pollen (BYOP):** Built-in API key support for users to query models using their own Pollen balance.
- **Responsive Design:** Dark cyberpunk/glassmorphism UI optimized for desktop and mobile.

## 🛠️ Built With
- **Pollinations.ai API:** `https://gen.pollinations.ai/v1/chat/completions`
- Single-file zero-dependency static web app.
